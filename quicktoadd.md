# toadd → New Repo Workflow

## 1. Selection
Pick candidate from `toadd.md`

## 2. Proposal
Proffer:
- Candidate bookplate (the `.v` file header/dedication)
- Repo name
- Repo description
- Tags

## 3. Approval
User approves or rejects/modifies

## 4. Execution (on approval)
- Create the GitHub repo
- Add `bookplate.v`
- Add entry to `INDEX.md`
- Remove from `toadd.md`

## 5. Implementation
Build out the actual formalization
